# InterviewX

Accessible responsive interview-preparation web app based on the supplied HTML prototype.

- Frontend: `public/index.html`
- Public runtime config: `public/config.js` (placeholders only; no secrets)
- Database, row-level security and private resume storage: `supabase/schema.sql`
- AI answer evaluation Edge Function template: `supabase/functions/evaluate-answer/`
- Deployment and launch checklist: `DEPLOYMENT.md`

**Important:** A live public URL and real production backend require your hosting and Supabase accounts to be connected and configured. This source package does not claim that deployment has already happened.
